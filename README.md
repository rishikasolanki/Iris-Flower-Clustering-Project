# Iris Flower Clustering Project

## Overview
This project demonstrates Unsupervised Machine Learning using the Iris Dataset. K-Means Clustering is applied to group iris flowers into three clusters, while PCA is used to reduce dimensions for better visualization.

## Dataset
- Iris Dataset (UCI / Kaggle)
- Features: Sepal Length, Sepal Width, Petal Length, Petal Width

## Objectives
- Apply K-Means Clustering (k=3)
- Visualize clusters using scatter plots
- Perform dimensionality reduction with PCA
- Compare predicted clusters with actual flower species

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Results
- Successfully clustered iris flowers into 3 groups.
- Reduced dataset dimensions using PCA.
- Visualized clusters in 2D space.
- Compared cluster assignments with true labels.
